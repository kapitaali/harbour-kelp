## Discoveries

### i486 target is broken
- The i486 target directory exists at /home/theb/SailfishOS/mersdk/targets/SailfishOS-5.1.0.11-i486.default/
- But qmake binary is MISSING from usr/lib/qt5/bin/ (directory is empty)
- No qmake binary exists anywhere in any target (aarch64, armv7hl also empty in usr/lib*/qt5/bin/)
- qmake only exists as a wrapper script in ~/.config/SailfishSDK/libsfdk/build-target-tools/ which delegates to the build engine
- SDK Maintenance Tool reports "no updates available"
- manage.sh is for virtual repository management, not target repair
- Conclusion: i486 target was incompletely installed; cannot be repaired via SDK tools. User would need to reinstall from SDK installer or use a different machine.

### Build engine has 180s timeout
- sfdk build-shell commands consistently time out at 180s
- Even with timeout= parameter set to 600s, still times out at 180s
- This is a hard limit of the build engine environment
- Tests that take longer than 180s to compile+run cannot be executed in this environment
- Workaround: run individual test suites one at a time, or run make directly in build-shell
