# Progress — 2026-11-08

## 0.1.0 submitted to Jolla Harbour

### What was built since 2026-11-04

**WS-C2: Full-bundle streaming (landed in 0.1.0)**

- Phase 1: manifest-first fetch in stream mode + `receiveMode` setting (store/stream, default store)
- Phase 2: true streaming — per-file sequential chunk fetch, no store for content objects
- Phase 3+4: QML receive mode selector in Settings, cleanup notes
- Design doc: `META-INF/WS-C2-streaming-design.md`
- Verified: i486 build, aarch64 build, armv7hl build, all test suites pass

**Other changes landed:**
- WS-A1: auto-prune unused objects on unshare + setting
- WS-A2: per-bundle receive acceptance tracking + confirmation dialog
- WS-A3: gateway passphrase (`#p=`) unwrap via PBKDF2 + AES-GCM
- WS-A4: run-emu-share.sh VM/bridge address tier
- WS-C1: relay-side object cache (LRU, 64 MiB)
- WS-G6: per-bundle confirmation dialog before download
- Storage cleanup button moved to top of Settings page
- Snap-like ephemeral model: no re-share, no keep-received bundles
- `receiveMode` setting: store (default) or stream (experimental)
