## What was fixed for Harbour (do not undo)

- `qml/pages/FolderPickPage.qml` uses Harbour-allowed
  `Qt.labs.folderlistmodel 2.1`. `Nemo.FileManager` is not importable from an app
  and must not return.
- `harbour-kelp.desktop` uses `Exec=harbour-kelp %u`. Harbour rejects the
  `invoker --type=silica-qt5` form.
- `rpm/harbour-kelp.spec` has **no** `%post`/`%postun` and no `/bin/sh`
  dependency. The platform's own desktop-database handling still registers
  `x-scheme-handler/kelp` on a clean install; this was verified.
- `rpm/harbour-kelp.changes.run` falls back to the hand-written
  `rpm/harbour-kelp.changes` when the first release has no git tag, so the RPM
  does not ship an empty `%changelog`.
- `%define kelp_dev_extras 0` is the release setting. Do not flip it back for the
  upload build.
